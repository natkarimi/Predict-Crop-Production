# Predict Crop Production using Machine Learning

## Project Overview
This project analyzes agricultural crop production data using Python and machine learning techniques. The goal is to explore patterns in crop area, production, and yield across different states and years.

## Dataset
The dataset contains agricultural statistics including:
- Crop area (hectares)
- Crop production (tons)
- Crop yield (kg per hectare)
- State and district information
- Data collected across multiple years

## Methods Used
The project includes:

- Data cleaning and preprocessing
- Handling missing values
- Exploratory Data Analysis (EDA)
- Visualization using scatter plots and box plots
- Crop distribution analysis

## Tools & Technologies
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Google Colab

## Project Files
- `crop-production-analysis.ipynb` – main notebook with analysis
- `cropsdataset.csv` – dataset used for analysis
- `crop-production-analysis.pdf` – exported notebook report
